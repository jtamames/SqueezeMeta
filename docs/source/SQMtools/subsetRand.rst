========== ===============
subsetRand R Documentation
========== ===============

Select random ORFs
------------------

Description
~~~~~~~~~~~

Create a random subset of a SQM object.

Usage
~~~~~

.. code:: R

   subsetRand(SQM, N)

Arguments
~~~~~~~~~

======= =========================================
``SQM`` SQM object to be subsetted.
``N``   numeric. number of random ORFs to select.
======= =========================================

Value
~~~~~

SQM object containing a random subset of ORFs.

See Also
~~~~~~~~

``subsetORFs``
